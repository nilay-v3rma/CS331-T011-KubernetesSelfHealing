# AI Usage: Operator and Kubernetes API

AI assistance was used to understand and document the operator and Kubernetes API part of the project.

The help was mainly used for:

- explaining the `NetworkHealthCheck` custom resource;
- describing how the controller discovers agent pods;
- documenting how probe results are written back into Kubernetes status;
- connecting controller behavior with metrics and status fields.

The final description was checked against the actual CRD, controller code, and sample manifest.
