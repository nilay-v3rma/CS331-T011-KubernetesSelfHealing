# AI Usage: Distributed Probe Agent

AI assistance was used to reason about the probe-agent design and explain it clearly.

The help was mainly used for:

- describing why one agent should run on every node;
- explaining why the operator should orchestrate probes instead of sending all probes itself;
- documenting the agent endpoints and probe result fields;
- connecting agent-level measurements to network metrics such as RTT, loss, jitter, burst loss, and throughput.

The final code was kept consistent with the existing project structure.
