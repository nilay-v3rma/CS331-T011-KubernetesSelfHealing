The Effect of line 1: #!/bin/bash: No such file or directory
1. What Caused It

When the script was normalized on Windows, PowerShell wrote a 3-byte invisible UTF-8 Byte Order Mark (BOM) (0xEF 0xBB 0xBF) at byte offset 0 before #!/bin/bash.

2. What the Effect Is

  
Shebang Ignored by Linux Kernel: The Linux kernel requires the exact magic bytes 0x23 0x21 (#!) at byte 0 to identify the interpreter. Because the 3-byte BOM was in front, the kernel did not recognize the shebang.

  
Fall-Through Execution: Because your interactive terminal was already running bash, Linux fell back to executing the file line-by-line in the current shell. When it reached line 1, it tried to run the literal word #!/bin/bash as a command, printed the error No such file or directory, and then proceeded to run the rest of the script.
