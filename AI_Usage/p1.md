# AI Usage: Platform and Deployment

AI assistance was used to understand and organize the platform setup work for the Kubernetes connectivity project.

AI was also used to initially generate parts of the project report. The generated report text was manually verified against the code, manually rewritten for clarity and consistency, and the PPT was prepared manually.

The help was mainly used for:

- understanding the KIND cluster setup;
- describing why a multi-node cluster is needed;
- checking how Calico fits into the pod-to-pod networking problem;
- improving documentation around setup commands and project structure.

The final implementation and verification were checked against the repository files and the project objective.
