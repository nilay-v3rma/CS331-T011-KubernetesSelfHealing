# AI Usage: Analysis and Failure Classification

AI assistance was used to explain the analysis and classification layer in simple academic language.

AI was also used to initially generate parts of the project report. The generated report text was manually verified against the code, manually rewritten for clarity and consistency, and the PPT was prepared manually.

The help was mainly used for:

- describing the directed reachability matrix;
- explaining row-shaped, column-shaped, isolated-node, pair-local, policy-scoped, and cluster-wide failures;
- documenting why the classifier can use rules instead of machine learning;
- connecting classifier output with the project objective of locating likely failure causes.

The final report text was kept consistent with the classifier behavior and fixture cases in the repository.
